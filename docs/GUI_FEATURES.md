# Возможности GUI

## Главное окно

### Вкладка "Проекты"

#### Командная панель
Расположена над таблицей проектов и содержит кнопки:

```
[Добавить] [Изменить] [Копировать] [Удалить]
```

- **Добавить** (зеленая) - создание нового проекта
- **Изменить** (синяя) - редактирование выбранного проекта
- **Копировать** (розовая) - копирование выбранного проекта
- **Удалить** (красная) - удаление выбранного проекта

#### Таблица проектов
Отображает список всех проектов с колонками:
- ✓ - чекбокс выбора для конвертации
- Наименование - имя проекта
- Скрипт - тип конвертации
- Путь выгрузки - путь назначения

**Действия:**
- Клик по строке - переключение чекбокса выбора
- Выбранная строка подсвечивается

#### Панель управления выбором
```
[Выбрать все] [Снять все] [Вверх ▲] [Вниз ▼] [Изменить путь...] [Обновить проекты]
```

#### Детали проекта
Таблица с параметрами выбранного проекта:
- Параметр - имя параметра
- Значение - текущее значение
- Описание - описание параметра

Показывает объединенные параметры из базового .env и .env проекта.

### Вкладка "Лог выполнения"

Отображает вывод конвертации в реальном времени с цветовой подсветкой:
- 🟢 Зеленый - успешные операции
- 🔴 Красный - ошибки
- 🟡 Желтый - предупреждения
- 🔵 Синий - информационные сообщения
- ⚪ Серый - отладочная информация

**Кнопки:**
- [Очистить лог] - очистка вывода
- [Сохранить лог] - сохранение в файл

**Контекстное меню (правый клик):**
- Копировать - копирование выделенного текста
- Выделить все - выделение всего текста

### Панель выполнения

Расположена внизу окна:

```
Готов к запуску
[████████████████████████████████] 0%

[ВЫПОЛНИТЬ (F5)]  ☑ Отладка
```

- Прогресс-бар - отображает прогресс выполнения
- Кнопка ВЫПОЛНИТЬ - запуск конвертации (горячая клавиша F5)
- Чекбокс Отладка - включение режима отладки

## Форма редактирования проекта

Открывается при нажатии кнопок Добавить/Изменить/Копировать.

### Обязательные поля

```
Наименование: [_________________________]
Скрипт:       [conf2cf ▼]
```

### Параметры проекта

Каждый параметр представлен строкой:

```
☑ V8_SRC_PATH:     [C:\Projects\MyConfig]  [...]
☑ V8_DST_PATH:     [C:\Output\config.cf]   [...]
☐ V8_VERSION:      [8.3.23.2040]
☐ V8_ENCODING:     [65001]
☐ V8_CONVERT_TOOL: [0 ▼]  (для булевых)
```

**Элементы:**
- ☑/☐ - чекбокс включения параметра
- Метка - имя параметра (при наведении показывается подсказка)
- Поле ввода - значение параметра
- [...] - кнопка выбора файла/папки (для путей)
- [▼] - выпадающий список (для булевых: 0 или 1)

**Сортировка:**
1. Обязательные параметры (всегда включены)
2. Включенные необязательные параметры
3. Выключенные необязательные параметры

### Базовый .env (только для просмотра)

Таблица внизу формы показывает параметры из базового .env файла:

```
┌──────────────┬─────────────────┬────────────────────────────┐
│ Параметр     │ Значение        │ Описание                   │
├──────────────┼─────────────────┼────────────────────────────┤
│ V8_VERSION   │ 8.3.23.2040     │ Версия платформы 1С        │
│ V8_TOOL      │ C:\1cv8\...     │ Путь к 1cv8.exe            │
└──────────────┴─────────────────┴────────────────────────────┘
```

### Кнопки действий

```
[Сохранить]  [Отменить]
```

- **Сохранить** (зеленая) - сохранение изменений
- **Отменить** (красная) - отмена без сохранения

## Горячие клавиши

- **F5** - запуск конвертации (аналог кнопки ВЫПОЛНИТЬ)

## Цветовая схема Cyberpunk

- Фон: темно-синий (#0f0f1e)
- Вторичный фон: темно-серый (#1a1a2e)
- Основной цвет: неоново-синий (#00d9ff)
- Акцент: неоново-розовый (#ff006e)
- Успех: неоново-зеленый (#00ff88)
- Ошибка: неоново-красный (#ff0055)
- Предупреждение: желтый (#ffdd00)
- Текст: светло-серый (#e0e0e0)
- Приглушенный текст: серый (#808080)

## Примеры использования

### Создание проекта для конвертации конфигурации

1. Нажмите **Добавить**
2. Заполните:
   - Наименование: `МояКонфигурация`
   - Скрипт: `conf2cf`
   - V8_SRC_PATH: `C:\Projects\MyConfig` (выберите через [...])
   - V8_DST_PATH: `C:\Output\config.cf` (выберите через [...])
3. Включите дополнительные параметры при необходимости:
   - ☑ V8_VERSION: `8.3.23.2040`
   - ☑ V8_CONF_CLEAN_DST: `1`
4. Нажмите **Сохранить**

### Копирование проекта с изменением параметров

1. Выберите проект в таблице
2. Нажмите **Копировать**
3. Измените:
   - Наименование: `МояКонфигурация_Копия`
   - V8_DST_PATH: `C:\Output\config_copy.cf`
4. Нажмите **Сохранить**

### Изменение типа конвертации

1. Выберите проект в таблице
2. Нажмите **Изменить**
3. Измените:
   - Скрипт: `conf2xml` (вместо `conf2cf`)
   - V8_DST_PATH: `C:\Output\xml\` (папка вместо файла)
4. Нажмите **Сохранить**

### Пакетная конвертация

1. Выберите несколько проектов (клик по строкам)
2. Или нажмите **Выбрать все**
3. Нажмите **ВЫПОЛНИТЬ** или F5
4. Следите за прогрессом в логе
5. Дождитесь завершения всех проектов

## Советы и рекомендации

### Организация проектов

- Используйте понятные имена проектов
- Группируйте связанные проекты по префиксам (например: `Prod_`, `Test_`)
- Создайте базовый .env с общими параметрами

### Работа с параметрами

- Включайте только необходимые параметры
- Используйте подсказки для понимания назначения параметров
- Проверяйте пути перед сохранением

### Отладка

- Включайте режим отладки при возникновении проблем
- Сохраняйте логи для анализа ошибок
- Проверяйте команды в логе отладки

### Производительность

- Не запускайте слишком много проектов одновременно
- Используйте SSD для временных файлов
- Закрывайте другие приложения 1С во время конвертации
