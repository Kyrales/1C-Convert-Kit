# Рефакторинг GUI модуля - Версия 1.2.1

## Дата: 31 января 2026

## Цель рефакторинга

Разделение монолитного файла `src/gui/main.py` (1722 строки) на модульную структуру для улучшения читаемости, поддерживаемости и тестируемости кода.

## Выполненные изменения

### 1. Создана модульная структура

Исходный файл `src/gui/main.py` разделен на следующие модули:

#### `src/gui/constants.py`
- Версия приложения (VERSION = "1.2.1")
- Цветовая схема Cyberpunk (COLORS)
- Пути к ключевым файлам и папкам

#### `src/gui/utils.py`
- Вспомогательная функция `format_duration()` для форматирования времени

#### `src/gui/project_scanner.py`
- Класс `ProjectScanner` для сканирования и загрузки проектов
- Методы чтения .env файлов

#### `src/gui/project_editor.py`
- Класс `ProjectEditorDialog` для добавления/изменения/копирования проектов
- Валидация имен проектов
- Динамическое создание форм на основе `params_descriptions.json`
- Обработка различных типов параметров (пути, булевы значения, текст)

#### `src/gui/conversion_runner.py`
- Класс `ConversionRunner` для запуска конвертации проектов
- Обработка вывода subprocess с поддержкой разных кодировок
- Цветное логирование

#### `src/gui/main_window.py`
- Класс `CyberpunkGUI` - главное окно приложения
- Создание layout интерфейса
- Обработка событий
- CRUD операции с проектами

#### `src/gui/main.py`
- Минимальная точка входа (30 строк)
- Проверка наличия зависимостей
- Запуск главного окна

#### `src/gui/__init__.py`
- Экспорт публичных классов и функций
- Упрощенный импорт для внешних модулей

### 2. Преимущества новой структуры

✅ **Модульность**: Каждый класс в отдельном файле
✅ **Читаемость**: Файлы по 200-500 строк вместо 1722
✅ **Тестируемость**: Легко писать unit-тесты для отдельных модулей
✅ **Поддерживаемость**: Проще находить и исправлять ошибки
✅ **Расширяемость**: Легко добавлять новые функции
✅ **Переиспользование**: Классы можно использовать независимо

### 3. Обратная совместимость

Все существующие функции сохранены:
- Добавление/изменение/копирование/удаление проектов
- Валидация имен проектов
- Динамические формы параметров
- Цветное логирование
- Отладочный режим
- Сохранение логов

### 4. Структура файлов

```
src/gui/
├── __init__.py              # Экспорт публичных классов
├── constants.py             # Константы и пути
├── utils.py                 # Вспомогательные функции
├── project_scanner.py       # Сканирование проектов
├── project_editor.py        # Диалог редактирования проекта
├── conversion_runner.py     # Запуск конвертации
├── main_window.py           # Главное окно
└── main.py                  # Точка входа
```

### 5. Использование

#### Запуск приложения
```bash
python src/gui/main.py
# или
python run_gui.cmd
```

#### Импорт в коде
```python
from src.gui import CyberpunkGUI, VERSION, COLORS

# Создание GUI
gui = CyberpunkGUI()
gui.handle_events()
```

### 6. Тестирование

Все модули успешно компилируются:
```bash
python -m py_compile src/gui/*.py
```

Импорт работает корректно:
```python
from src.gui import CyberpunkGUI, VERSION
print(f'Версия: {VERSION}')  # Версия: 1.2.1
```
