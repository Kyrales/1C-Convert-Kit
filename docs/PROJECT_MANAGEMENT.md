# Управление проектами в GUI

Через GUI можно создавать, изменять, копировать и удалять проекты конвертации.

## Возможности

### Командная панель

Над таблицей проектов расположена панель с кнопками:

- **Добавить** — создать проект
- **Изменить** — открыть выбранный проект для редактирования
- **Копировать** — создать копию выбранного проекта
- **Удалить** — удалить выбранный проект

### Добавление проекта

1. Нажмите кнопку **Добавить**
2. Откроется форма с полями:
   - **Наименование** - имя проекта (обязательное)
   - **Скрипт** - тип конвертации из выпадающего списка (обязательное)
   - **V8_SRC_PATH** - путь к источнику (если требуется для скрипта)
   - **V8_DST_PATH** - путь назначения (если требуется для скрипта)
   - Дополнительные параметры из `params_descriptions.json`

3. Каждый необязательный параметр имеет чекбокс для включения/выключения
4. Для путей доступна кнопка **...** для выбора файла/папки
5. Для булевых параметров доступен выбор 0 или 1
6. При наведении на параметр отображается подсказка с описанием
7. Внизу формы отображается таблица с параметрами из базового .env (только для просмотра)
8. Нажмите **Сохранить** для создания проекта или **Отменить** для отмены

Программа создаст каталог `projects/Наименование/` и файл `Наименование_Скрипт.env`.

### Изменение проекта

1. Выберите проект в таблице
2. Нажмите кнопку **Изменить**
3. Откроется форма с текущими значениями параметров
4. Измените необходимые поля
5. Нажмите **Сохранить**

**Результат:** 
- Если изменилось наименование - папка переименовывается
- Если изменился скрипт - .env файл переименовывается
- Параметры обновляются в .env файле

### Копирование проекта

1. Выберите проект в таблице
2. Нажмите кнопку **Копировать**
3. Откроется форма с параметрами выбранного проекта
4. Измените наименование и другие параметры по необходимости
5. Нажмите **Сохранить**

**Результат:** Создается новый проект с указанными параметрами

### Удаление проекта

1. Выберите проект в таблице
2. Нажмите кнопку **Удалить**
3. Подтвердите удаление в диалоге
4. Нажмите **Да** для удаления или **Нет** для отмены

**Результат:** Папка проекта удаляется полностью со всем содержимым

## Валидация

### Наименование проекта

- Не может быть пустым
- Не может содержать недопустимые символы: `/\:*?"<>|`
- Не может совпадать с именем существующего проекта
- Пробелы в имени заменяются на подчеркивания в имени файла

### Обязательные поля

- **Наименование** - всегда обязательно
- **Скрипт** - всегда обязательно
- **V8_SRC_PATH** - обязательно если требуется для выбранного скрипта
- **V8_DST_PATH** - обязательно если требуется для выбранного скрипта
- **V8_EXT_NAME** - обязательно для скриптов работы с расширениями

Обязательные поля всегда включены и не могут быть отключены.

## Сортировка параметров

Параметры в форме отображаются в следующем порядке:

1. **Обязательные параметры** (всегда включены)
2. **Включенные необязательные параметры** (есть в .env файле)
3. **Выключенные необязательные параметры** (отсутствуют в .env файле)
4. **Базовый .env** (отдельная таблица внизу, только для просмотра)

Внутри каждой группы параметры отсортированы по алфавиту.

## Типы параметров

### Текстовые поля
Обычный ввод текста

### Булевы поля
Выбор из списка: 0 или 1

### Пути к файлам
Поле ввода + кнопка **...** для выбора файла

### Пути к папкам
Поле ввода + кнопка **...** для выбора папки

## Базовый .env файл

Если в корне папки `projects/` есть .env файл, его параметры отображаются внизу формы в отдельной таблице.

Эти параметры:
- Доступны только для просмотра
- Не могут быть изменены через GUI
- Не сохраняются в .env файл проекта
- Используются как значения по умолчанию при конвертации

Базовый `.env`-файл редактируется вручную.

## Изменение типа скрипта

При изменении типа скрипта в форме:
- Форма пересоздается с новым набором параметров
- Значения общих параметров сохраняются
- Значения специфичных для старого скрипта параметров теряются

## Формат .env файла

Файл сохраняется в формате:

```env
ScriptName=conf2cf
V8_DST_PATH=output.cf
V8_SRC_PATH=C:\Projects\MyConfig
V8_VERSION=8.3.27.1989
```

- Параметр `ScriptName` всегда первый
- Остальные параметры в алфавитном порядке
- Значения с пробелами заключаются в кавычки
- Пустые параметры не сохраняются
