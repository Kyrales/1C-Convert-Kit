# Решение проблем

## Проблемы с управлением проектами

### Ошибка: "Наименование содержит недопустимый символ"

**Причина:** Имя проекта содержит символы, недопустимые для имен папок в Windows.

**Решение:** Удалите из имени следующие символы: `/\:*?"<>|`

**Пример:**
- ❌ Неправильно: `Проект/Тест`
- ✅ Правильно: `Проект_Тест`

### Ошибка: "Проект с именем 'X' уже существует"

**Причина:** Проект с таким именем уже создан.

**Решение:** 
- Используйте другое имя
- Или удалите существующий проект перед созданием нового

### Ошибка: "Не заполнены обязательные поля"

**Причина:** Не указаны обязательные параметры для выбранного типа скрипта.

**Решение:** Заполните все обязательные поля:
- Наименование
- Скрипт
- V8_SRC_PATH (если требуется)
- V8_DST_PATH (если требуется)
- V8_EXT_NAME (для расширений)

### Ошибка при создании папки проекта

**Причина:** Недостаточно прав или папка уже существует.

**Решение:**
- Проверьте права доступа к папке `projects/`
- Убедитесь, что папка с таким именем не существует
- Запустите приложение от имени администратора

### Ошибка при удалении проекта

**Причина:** Файлы проекта используются другим процессом.

**Решение:**
- Закройте все приложения, использующие файлы проекта
- Закройте проводник Windows в папке проекта
- Перезапустите приложение

## Проблемы с формой редактирования

### Не отображаются параметры для скрипта

**Причина:** Отсутствует или поврежден файл `params_descriptions.json`.

**Решение:**
- Проверьте наличие файла `src/config/params_descriptions.json`
- Проверьте корректность JSON синтаксиса
- Восстановите файл из репозитория

### Не работает кнопка выбора файла/папки

**Причина:** Параметр не включен (чекбокс не отмечен).

**Решение:** Включите параметр, отметив чекбокс слева от имени параметра.

### Форма не сохраняет изменения

**Причина:** Ошибка валидации или недостаточно прав.

**Решение:**
- Проверьте все обязательные поля
- Проверьте имя проекта на недопустимые символы
- Проверьте права доступа к папке `projects/`

### При смене скрипта теряются значения полей

**Причина:** Это нормальное поведение - разные скрипты имеют разные параметры.

**Решение:** 
- Сохраняются только общие параметры
- Специфичные параметры нужно заполнить заново
- Используйте копирование проекта вместо изменения типа скрипта

## Проблемы с конвертацией

### Ошибка: "Не найден скрипт convert.py"

**Причина:** Неправильная структура проекта или запуск из неправильной папки.

**Решение:**
- Запускайте GUI из корня проекта
- Проверьте наличие файла `src/core/convert.py`
- Используйте скрипты `run_gui.cmd` или `run_gui.sh`

### Конвертация зависает

**Причина:** Длительная операция или зависание процесса 1С.

**Решение:**
- Дождитесь завершения (может занять несколько минут)
- Включите режим отладки для просмотра команд
- Проверьте процессы 1С в диспетчере задач
- Перезапустите приложение

### Ошибки кодировки в логе

**Причина:** Проблемы с кодировкой вывода subprocess.

**Решение:**
- Обновите приложение до последней версии
- Используйте параметр `V8_ENCODING=65001` в .env
- Проверьте кодировку консоли Windows

### Не создаются выходные файлы

**Причина:** Ошибка в параметрах или недостаточно прав.

**Решение:**
- Проверьте правильность путей в V8_SRC_PATH и V8_DST_PATH
- Проверьте права доступа к папкам
- Проверьте наличие свободного места на диске
- Просмотрите лог для деталей ошибки

## Проблемы с базовым .env

### Базовый .env не отображается в форме

**Причина:** Файл отсутствует или находится не в корне `projects/`.

**Решение:**
- Создайте .env файл в корне папки `projects/`
- Убедитесь, что файл имеет расширение `.env`
- Перезапустите приложение

### Параметры из базового .env не применяются

**Причина:** Параметры переопределены в .env проекта.

**Решение:**
- Это нормальное поведение - проект переопределяет базовые параметры
- Удалите параметр из .env проекта, чтобы использовать базовое значение
- Проверьте таблицу деталей проекта для просмотра итоговых значений

## Проблемы с GUI

### Окно не открывается

**Причина:** Отсутствуют зависимости или ошибка импорта.

**Решение:**
```bash
# Установите зависимости
pip install -r requirements.txt

# Проверьте установку FreeSimpleGUI
pip install FreeSimpleGUI

# Или используйте PySimpleGUI
pip install PySimpleGUI
```

### Окно слишком маленькое/большое

**Причина:** Настройки размера окна в коде.

**Решение:**
- Измените размер окна вручную (окно изменяемого размера)
- Или измените параметр `size` в коде `src/gui/main.py`

### Таблица не обновляется

**Причина:** Кэширование данных.

**Решение:**
- Нажмите кнопку **Обновить проекты**
- Перезапустите приложение

### Не работают горячие клавиши

**Причина:** Фокус на другом элементе.

**Решение:**
- Кликните на главное окно
- Убедитесь, что не открыты диалоговые окна

## Проблемы с производительностью

### Медленная работа при большом количестве проектов

**Причина:** Много проектов в папке `projects/`.

**Решение:**
- Архивируйте неиспользуемые проекты
- Удалите временные файлы из папки `temp/`
- Используйте SSD вместо HDD

### Высокое потребление памяти

**Причина:** Большие логи или много одновременных конвертаций.

**Решение:**
- Очищайте лог регулярно
- Не запускайте слишком много проектов одновременно
- Перезапускайте приложение после длительной работы

## Получение помощи

Если проблема не решена:

1. **Включите режим отладки** и сохраните лог
2. **Проверьте файл ERROR.txt** в папке `temp/`
3. **Создайте issue** на GitHub с описанием проблемы и логом
4. **Укажите версию** приложения и платформы 1С

### Полезная информация для отчета об ошибке

```
Версия приложения: 1.2.0
Версия Python: 3.x.x
Версия 1С: 8.3.x.xxxx
ОС: Windows 10/11
Тип операции: Добавление/Изменение/Удаление/Конвертация
Текст ошибки: [скопируйте из лога]
```

## Известные ограничения

- Имена проектов не могут содержать символы: `/\:*?"<>|`
- Базовый .env можно редактировать только вручную
- При смене типа скрипта теряются специфичные параметры
- Одновременно может выполняться только одна конвертация
- Максимальная длина имени проекта ограничена ОС (обычно 255 символов)

## Советы по предотвращению проблем

1. **Регулярно делайте резервные копии** папки `projects/`
2. **Используйте понятные имена** без специальных символов
3. **Проверяйте пути** перед сохранением проекта
4. **Закрывайте другие приложения 1С** во время конвертации
5. **Следите за свободным местом** на диске
6. **Обновляйте приложение** до последней версии
7. **Читайте логи** для понимания причин ошибок
