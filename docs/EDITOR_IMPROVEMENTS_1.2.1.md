# Улучшения диалога редактирования проекта - Версия 1.2.1

## Дата: 31 января 2026

## Внесенные улучшения

### 1. Кнопка помощи "?" для каждого параметра ✅

**Проблема:** Описание параметра было доступно только через tooltip при наведении мыши.

**Решение:** 
- Добавлена кнопка "?" справа от каждого поля ввода
- При нажатии открывается всплывающее окно с полным описанием параметра
- Описание берется из `params_descriptions.json`

**Расположение:** После поля ввода, перед кнопкой "..." (если есть)

**Пример использования:**
```
[✓] V8_SRC_PATH: [________________] [?] [...]
```

При нажатии на "?" показывается:
```
Параметр: V8_SRC_PATH

Путь к источнику конфигурации (CF файл, XML каталог или EDT проект)
```

### 2. Поддержка буфера обмена (Ctrl+C / Ctrl+V) ✅

**Проблема:** В полях ввода не работали стандартные комбинации клавиш для копирования/вставки.

**Решение:**
- Добавлено контекстное меню (правый клик) с опциями:
  - **Копировать** - копирует выделенный текст
  - **Вставить** - вставляет из буфера обмена
  - **Вырезать** - вырезает выделенный текст
  - **Выделить все** - выделяет весь текст в поле
  - **Отменить** - отменяет последнее действие
- Включена поддержка undo/redo для всех полей Input
- Контекстное меню автоматически обрабатывает все операции через Tkinter

**Важно:** Стандартные комбинации клавиш (Ctrl+C/V/X/A/Z) работают **автоматически** через контекстное меню Tkinter. Не требуется дополнительных биндингов.

**Технические детали:**
```python
# Контекстное меню для каждого поля
right_click_menu = ['', ['Копировать', 'Вставить', 'Вырезать', 'Выделить все', '---', 'Отменить']]
input_field = sg.Input(..., right_click_menu=right_click_menu)

# Включение undo/redo
for key in self.window.AllKeysDict:
    if key.startswith('-VAL_'):
        element = self.window[key]
        if hasattr(element, 'Widget'):
            element.Widget.configure(undo=True, maxundo=-1)

# Обработка событий контекстного меню
elif event == 'Копировать':
    focused = self.window.find_element_with_focus()
    if focused and hasattr(focused, 'Widget'):
        selected = focused.Widget.selection_get()
        if selected:
            self.window.TKroot.clipboard_clear()
            self.window.TKroot.clipboard_append(selected)
```

**Как использовать:**
1. **Через контекстное меню:** Правый клик на поле → выбрать действие
2. **Через клавиатуру:** Стандартные комбинации Ctrl+C/V/X работают автоматически благодаря контекстному меню Tkinter

### 3. Улучшенный диалог выбора файла/папки ✅

**Проблема:** 
- Непонятно было, какой диалог откроется (файл или папка)
- Не подставлялся текущий путь в диалог выбора

**Решение:**
- Диалог выбора открывается сразу (без промежуточных окон)
- Тип диалога определяется автоматически по типу параметра:
  - `path_folder` → диалог выбора папки
  - `path_file` → диалог выбора файла
- Если поле уже заполнено, текущий путь подставляется в диалог:
  - Для файлов: подставляется полный путь к файлу
  - Для папок: подставляется путь к папке
  - Если путь не существует: подставляется родительская папка

**Технические детали:**
```python
# Получаем текущее значение
current_value = values[value_key]
initial_folder = None

if current_value:
    current_path = Path(current_value)
    if current_path.exists():
        if current_path.is_file():
            initial_folder = str(current_path.parent)
        else:
            initial_folder = str(current_path)
    else:
        initial_folder = str(current_path.parent)

# Открываем диалог с начальным путем
if param_type == 'path_folder':
    path = sg.popup_get_folder('Выберите папку', default_path=initial_folder or '')
else:
    path = sg.popup_get_file('Выберите файл', default_path=current_value or initial_folder or '')
```

### 4. Визуальное различие доступных/недоступных полей ✅

**Проблема:** Недоступные поля имели белый фон, что создавало впечатление, что их можно редактировать.

**Решение:**
- Доступные поля: светлый фон (`COLORS['bg_secondary']` = `#1a1a2e`)
- Недоступные поля: темный фон (`COLORS['bg']` = `#0f0f1e`)
- Цвет фона динамически меняется при включении/выключении чекбокса

**Визуальное отличие:**
```
Доступное поле:    [✓] Параметр: [████████████] ← светлый фон
Недоступное поле:  [ ] Параметр: [▓▓▓▓▓▓▓▓▓▓▓▓] ← темный фон
```

**Технические детали:**
```python
# Определяем цвет фона
disabled_bg = COLORS['bg']           # Темный для недоступных
enabled_bg = COLORS['bg_secondary']  # Светлее для доступных

# Применяем при создании
input_field = sg.Input(
    ...,
    background_color=enabled_bg if (is_enabled or is_required) else disabled_bg,
    disabled=not (is_enabled or is_required)
)

# Обновляем при изменении чекбокса
new_bg = COLORS['bg_secondary'] if is_checked else COLORS['bg']
window[value_key].update(disabled=not is_checked, background_color=new_bg)
```

1. Введите текст в любое поле (например, V8_VERSION: "8.3.23")

3. Нажмите Ctrl+C (или правый клик → Копировать)
4. Перейдите в другое поле
5. Нажмите Ctrl+V (или правый клик → Вставить)
6. Проверьте, что текст "8.3" вставился
7. Нажмите Ctrl+A - должен выделиться весь текст
8. Нажмите Ctrl+Z - должна отмениться последняя операция
