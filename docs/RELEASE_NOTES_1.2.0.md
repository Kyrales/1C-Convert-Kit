# Примечания к выпуску 1.2.0

**Дата выпуска:** 31 января 2026

## 🎉 Основные изменения

Версия 1.2.0 представляет **полноценное управление проектами через графический интерфейс**!

Теперь вы можете создавать, изменять, копировать и удалять проекты прямо из GUI, без необходимости ручного редактирования файлов и папок.

## ✨ Новые возможности

### 1. Управление проектами

Добавлена командная панель над таблицей проектов с кнопками:

- **Добавить** - создание нового проекта
- **Изменить** - редактирование существующего проекта
- **Копировать** - создание копии проекта
- **Удалить** - удаление проекта

### 2. Форма редактирования проекта

Новая визуальная форма для работы с проектами:

- ✅ Обязательные поля: Наименование, Скрипт, V8_SRC_PATH, V8_DST_PATH
- 🔘 Чекбоксы для включения/выключения необязательных параметров
- 📂 Кнопки выбора файлов и папок для параметров путей
- 💡 Подсказки с описанием параметров при наведении
- 📊 Отображение базового .env (только для просмотра)
- 🔄 Автоматическая сортировка параметров

### 3. Валидация

- Проверка имени проекта на недопустимые символы
- Проверка на дубликаты имен
- Проверка обязательных полей
- Автоматическая замена пробелов на подчеркивания в именах файлов

### 4. Автоматизация

- Автоматическое создание папок и .env файлов
- Автоматическое переименование при изменении проекта
- Автоматическое обновление списка проектов
- Автоматический выбор созданного/измененного проекта

## 📝 Примеры использования

### Создание проекта для конвертации конфигурации

```
1. Нажмите [Добавить]
2. Заполните:
   - Наименование: МояКонфигурация
   - Скрипт: conf2cf
   - V8_SRC_PATH: C:\Projects\MyConfig
   - V8_DST_PATH: C:\Output\config.cf
3. Нажмите [Сохранить]
```

### Копирование проекта

```
1. Выберите проект в таблице
2. Нажмите [Копировать]
3. Измените наименование и параметры
4. Нажмите [Сохранить]
```

### Изменение проекта

```
1. Выберите проект в таблице
2. Нажмите [Изменить]
3. Измените параметры
4. Нажмите [Сохранить]
```

### Удаление проекта

```
1. Выберите проект в таблице
2. Нажмите [Удалить]
3. Подтвердите удаление
```

## ⚠️ Важные изменения

### Формат ScriptName

В параметре `ScriptName` теперь указывается тип конвертации **без расширения .cmd**:

```env
# Правильно (новый формат)
ScriptName=conf2cf
ScriptName=dp2epf
ScriptName=ext2cfe

# Неправильно (старый формат)
ScriptName=conf2cf.cmd  # Не работает!
```

Старые проекты с `.cmd` в ScriptName продолжат работать, но рекомендуется обновить их через форму редактирования.

### Структура проектов

Проекты теперь должны находиться в подпапках `projects/`:

```
projects/
├── base_1.env              # Базовая конфигурация (опционально)
├── МойПроект/
│   └── МойПроект_conf2cf.env
└── ДругойПроект/
    └── ДругойПроект_dp2epf.env
```

## 🔄 Обновление с предыдущих версий

### С версии 1.1.x

1. Обновите код из репозитория
2. Проверьте структуру папки `projects/`
3. При необходимости переместите .env файлы в подпапки
4. Обновите `ScriptName` в .env файлах (уберите .cmd)

### Автоматическая миграция

Приложение автоматически сканирует папку `projects/` и находит все проекты в подпапках. Проекты в корне `projects/` игнорируются (кроме базового .env).
