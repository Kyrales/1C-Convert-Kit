# Отображение значений из базового .env в редакторе проекта

## Описание функциональности

В форме редактирования проекта теперь отображаются значения параметров из базового файла `base_1.env` в качестве информационных подсказок.

## Как это работает

### 1. Чекбокс выключен (параметр не переопределяется)

- В поле ввода отображается значение из `base_1.env` с пометкой `(base_1.env)`
- Например: `8.3.27.1989 (base_1.env)`
- Поле недоступно для редактирования (серый фон)
- Текст отображается приглушенным цветом
- **Важно:** Это значение НЕ сохраняется в проектный .env файл

### 2. Чекбокс включен (параметр переопределяется)

- Поле очищается и становится доступным для ввода
- Фон становится светлее (активное поле)
- Пользователь может ввести свое значение
- Введенное значение сохраняется в проектный .env файл

### 3. Чекбокс снова выключен

- Поле снова показывает значение из `base_1.env` с пометкой
- Введенное ранее значение не сохраняется

## Преимущества

✅ **Удобство:** Пользователь видит, какие значения унаследованы из базовой конфигурации  
✅ **Чистота:** Проектный .env не загромождается дублирующими параметрами  
✅ **Прозрачность:** Явно видно, откуда берется значение параметра  
✅ **Гибкость:** Легко переопределить любой параметр при необходимости

## Пример использования

### Базовый файл `projects/base_1.env`:
```env
V8_VERSION=8.3.27.1989
V8_TOOL="C:\Program Files\1cv8\8.3.27.1989\bin\1cv8.exe"
V8_TEMP=f:\1C\Projects\1c-convert-kit\temp
```

### В редакторе проекта:

**Параметр V8_VERSION (чекбокс выключен):**
```
☐ V8_VERSION: [8.3.27.1989 (base_1.env)    ] [?]
```
→ Значение не сохраняется в проектный .env

**Параметр V8_VERSION (чекбокс включен):**
```
☑ V8_VERSION: [8.3.28.2000                 ] [?]
```
→ Значение `8.3.28.2000` сохраняется в проектный .env

## Техническая реализация

### Изменения в `src/gui/project_editor.py`:

1. **Загрузка базового .env:**
   - Метод `_load_base_env()` загружает параметры из первого найденного .env файла в корне `projects/`

2. **Отображение значений:**
   - При создании layout проверяется состояние чекбокса
   - Если чекбокс выключен и есть значение в `base_env_params` → показывается с пометкой
   - Если чекбокс включен → показывается значение из проектного .env

3. **Обработка событий чекбокса:**
   - При включении чекбокса → поле очищается
   - При выключении чекбокса → показывается значение из `base_env_params` с пометкой

4. **Сохранение:**
   - Значения с пометкой `(base_1.env)` не сохраняются в проектный .env
   - Сохраняются только значения из включенных чекбоксов без пометки
