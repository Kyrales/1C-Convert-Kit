# Changelog - Версия 1.2.1

## [1.2.1] - 2026-01-31

### Добавлено

#### Рефакторинг GUI модуля
- ✅ Разделен монолитный файл `src/gui/main.py` (1722 строки) на модульную структуру
- ✅ Создано 8 отдельных модулей для улучшения читаемости и поддерживаемости
- ✅ Добавлен `src/gui/__init__.py` для упрощенного импорта

#### Новые модули
- `constants.py` - константы, цвета, пути
- `utils.py` - вспомогательные функции
- `project_scanner.py` - сканирование проектов
- `project_editor.py` - диалог редактирования проекта
- `conversion_runner.py` - запуск конвертации
- `main_window.py` - главное окно приложения
- `main.py` - точка входа (30 строк)

#### Улучшения диалога редактирования проекта

1. **Кнопка помощи "?"**
   - Добавлена кнопка "?" рядом с каждым параметром
   - При нажатии показывается полное описание параметра
   - Описание берется из `params_descriptions.json`

2. **Поддержка буфера обмена**
   - Исправлена работа Ctrl+C / Ctrl+V в полях ввода
   - Добавлена поддержка Ctrl+X, Ctrl+A, Ctrl+Z
   - Все стандартные комбинации клавиш теперь работают

3. **Улучшенный диалог выбора файла/папки**
   - Диалог открывается сразу без промежуточных окон
   - Автоматическое определение типа (файл или папка)
   - Подстановка текущего пути в диалог выбора
   - Умная обработка несуществующих путей

4. **Визуальное различие полей**
   - Доступные поля: светлый фон (#1a1a2e)
   - Недоступные поля: темный фон (#0f0f1e)
   - Динамическое изменение цвета при включении/выключении

### Технические детали

#### Структура файлов
```
src/gui/
├── __init__.py              # Экспорт публичных классов
├── constants.py             # Константы и пути (VERSION = "1.2.1")
├── utils.py                 # Вспомогательные функции
├── project_scanner.py       # Сканирование проектов
├── project_editor.py        # Диалог редактирования (улучшен)
├── conversion_runner.py     # Запуск конвертации
├── main_window.py           # Главное окно
└── main.py                  # Точка входа
```

#### Преимущества новой структуры
- ✅ Модульность: каждый класс в отдельном файле
- ✅ Читаемость: файлы по 200-500 строк вместо 1722
- ✅ Тестируемость: легко писать unit-тесты
- ✅ Поддерживаемость: проще находить и исправлять ошибки
- ✅ Расширяемость: легко добавлять новые функции
