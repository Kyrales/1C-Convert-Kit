# Python Docstrings

Навык гарантирует, что у всех новых и изменённых Python-функций есть краткие и содержательные docstrings.

## Когда вызывать
- При создании новых функций/методов/классов
- При изменении существующих функций, когда меняется поведение/аргументы/возвращаемые значения
- Перед публикацией тестов и утилит, если отсутствует описание

## Что делать
- Добавлять docstring сразу после объявления функции
- Структура:
  - Что делает функция (одной-двумя фразами)
  - Ключевые шаги/особенности (по необходимости)
  - Args: аргументы с краткими пояснениями
  - Returns: тип и значение, если есть
  - Raises: возможные исключения, если есть
  - Примеры (по необходимости, кратко)
- Язык: соответствовать языку проекта/пользователя (в этом репозитории — русский)

## Пример
```python
def import_config(db_path: Path, xml_path: Path) -> int:
    """
    Импортирует конфигурацию в существующую ИБ из XML (файловую или серверную).
    
    Args:
        db_path: Путь к файловой ИБ (игнорируется для серверного режима)
        xml_path: Путь к XML
    Returns:
        int: 0 при успехе
    Raises:
        ToolExecutionError: при ошибке выполнения инструмента
    """
```
