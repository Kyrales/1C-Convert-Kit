## Технические детали реализации

### Обработка кодировок
Все методы используют кодировку `cp1251` с параметром `errors='replace'` для корректной работы с выводом инструментов 1С на Windows.

### Парсинг логов
Используется класс `ToolOutputParser` из `converter.py`:
- Метод `read_file_with_encoding()` пробует разные кодировки (utf-8, cp1251, cp866, latin-1)
- Метод `parse_designer_log()` извлекает ошибки из лог-файлов designer
- Метод `has_errors()` проверяет наличие ошибок

### Обработка исключений
Все методы выбрасывают специализированные исключения:
- `ToolNotFoundError` - инструмент не найден
- `ToolExecutionError` - ошибка выполнения инструмента (с выводом tool_output)
- `subprocess.SubprocessError` - ошибка запуска процесса

### Учетные данные
Методы V8ToolWrapper и IbcmdToolWrapper получают учетные данные из env_vars:
- `V8_IB_USER` - имя пользователя ИБ
- `V8_IB_PWD` - пароль пользователя ИБ
- `V8_DB_SRV_USR` - пользователь СУБД (для серверных ИБ)
- `V8_DB_SRV_PWD` - пароль СУБД (для серверных ИБ)

### Поддержка расширений
Методы `load_config_from_files()`, `dump_config()` и `save_config()` поддерживают работу с расширениями через опциональный параметр `extension_name`.

Код поддерживает старый формат `ScriptName=conf2cf.cmd`:
```python
if script_name.endswith('.cmd'):
    script_name = script_name[:-4]
```

Код поддерживает запуск из разных директорий:
```python
try:
    from converters.registry import ConverterRegistry
except ImportError:

    sys.path.insert(0, str(Path(__file__).parent.parent))
    from converters.registry import ConverterRegistry
```
