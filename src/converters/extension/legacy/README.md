# Legacy CMD скрипты конвертации расширений

## Статус: УСТАРЕЛО

Эти CMD скрипты больше **НЕ ИСПОЛЬЗУЮТСЯ** в текущей версии приложения.

## История

Ранее конвертация расширений выполнялась через CMD скрипты:
- `ext2cfe.cmd` - конвертация в CFE файл
- `ext2xml.cmd` - конвертация в XML
- `ext2edt.cmd` - конвертация в EDT проект
- `ext2ib.cmd` - конвертация в информационную базу

## Текущая реализация

Вся функциональность перенесена в Python класс **ExtensionConverter**:
- Расположение: `src/converters/extension/converter.py`
- Использует объектно-ориентированный подход
- Интегрирован с ConverterRegistry
- Поддерживает все типы конвертации расширений
- Работает с базовой конфигурацией

## Использование

Для конвертации расширений используйте:

```python
from converters.extension.converter import ExtensionConverter

env_vars = {
    'V8_SRC_PATH': '/path/to/extension',
    'V8_DST_PATH': '/path/to/output.cfe',
    'V8_EXT_NAME': 'МоеРасширение',  # Обязательный параметр!
    # ... другие параметры
}

converter = ExtensionConverter(env_vars)
converter.validate()
converter.convert()
converter.cleanup()
```

Или через CLI:
```bash
python src/core/convert.py --env projects/MyExtension
```

## Особенности

ExtensionConverter требует:
- **V8_EXT_NAME** - обязательный параметр с именем расширения
- **V8_BASE_CONFIG** (опционально) - базовая конфигурация для загрузки расширения
- **V8_BASE_IB** (опционально) - готовая информационная база

Конвертер автоматически:
- Создает временную информационную базу
- Загружает базовую конфигурацию (если указана)
- Загружает расширение
- Выгружает в нужный формат

## Причины миграции

1. **Устранение дублирования кода** - общая логика вынесена в BaseConverter
2. **Валидация параметров** - проверка обязательного V8_EXT_NAME
3. **Лучшая тестируемость** - Python код легче тестировать
4. **Единообразная обработка ошибок** - централизованная обработка
5. **Гибкость** - поддержка различных инструментов (designer/ibcmd)
