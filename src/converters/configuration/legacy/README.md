# Legacy CMD скрипты конвертации конфигураций

## Статус: УСТАРЕЛО

Эти CMD скрипты больше **НЕ ИСПОЛЬЗУЮТСЯ** в текущей версии приложения.

## История

Ранее конвертация конфигураций выполнялась через CMD скрипты:
- `conf2cf.cmd` - конвертация в CF файл
- `conf2xml.cmd` - конвертация в XML
- `conf2edt.cmd` - конвертация в EDT проект
- `conf2ib.cmd` - конвертация в информационную базу

## Текущая реализация

Вся функциональность перенесена в Python класс **ConfigurationConverter**:
- Расположение: `src/converters/configuration/converter.py`
- Использует объектно-ориентированный подход
- Интегрирован с ConverterRegistry
- Поддерживает все типы конвертации

## Использование

Для конвертации конфигураций используйте:

```python
from converters.configuration.converter import ConfigurationConverter

converter = ConfigurationConverter(env_vars)
converter.validate()
converter.convert()
converter.cleanup()
```

Или через CLI:
```bash
python src/core/convert.py --env projects/MyProject
```

## Причины миграции

1. **Устранение дублирования кода** - общая логика вынесена в BaseConverter
2. **Автоматическое обнаружение** - ConverterRegistry находит конвертеры автоматически
3. **Лучшая тестируемость** - Python код легче тестировать
4. **Единообразная обработка ошибок** - централизованная обработка
5. **Расширяемость** - легко добавлять новые типы конвертации

## Сохранение

Эти файлы сохранены только для истории и справки. Они не участвуют в работе приложения.
