# Валидатор EDT проектов 1С

## Описание

`ValidationConverter` - конвертер для валидации EDT проектов 1С:Предприятие.

## Назначение

Проверяет корректность структуры EDT проекта перед конвертацией или развертыванием.

## Поддерживаемые форматы

### Входной формат:
- **EDT** - проект 1C:Enterprise Development Tools

### Выходной формат:
- Нет (валидация не создает выходных файлов)

## Обязательные параметры

- `V8_SRC_PATH` - путь к EDT проекту

## Опциональные параметры

- `RING_TOOL` - путь к ring.bat
- `EDT_TOOL` - путь к 1cedtcli.exe
- `V8_EDT_VERSION` - версия EDT (по умолчанию `2025.1.5`)

## Примеры использования

### Пример 1: Валидация конфигурации

```env
ScriptName=edt-validate
V8_SRC_PATH=C:/Projects/MyConfiguration
```

### Пример 2: Валидация расширения

```env
ScriptName=edt-validate
V8_SRC_PATH=C:/Projects/MyExtension
```

## Что проверяется

### Базовая структура:
- ✓ Наличие директории `DT-INF`
- ✓ Наличие файла `.project`
- ✓ Наличие `Configuration.xml` или `Extension.xml` в `DT-INF`
- ✓ Наличие директории `src` (опционально)

### Дополнительная информация:
- Тип проекта (конфигурация или расширение)
- Количество файлов в проекте
- Предупреждения о потенциальных проблемах

## Последовательность валидации

1. Проверка что источник является EDT проектом
2. Проверка наличия обязательных директорий и файлов
3. Определение типа проекта (конфигурация/расширение)
4. Подсчет файлов и вывод статистики
5. Вывод результатов валидации

## Коды возврата

- `0` - валидация прошла успешно
- `1` - обнаружены ошибки в структуре проекта

## Особенности

- **Быстрая проверка**: Валидация выполняется без создания временных файлов
- **Детальный вывод**: Все проверки логируются с указанием результата
- **Не требует платформу 1С**: Базовая валидация работает без установленной платформы
- **Расширяемость**: В будущем можно добавить более глубокую валидацию через EDT инструменты

## Обработка ошибок

При обнаружении ошибок:
1. Выводится подробное описание проблемы
2. Указывается что именно отсутствует или некорректно
3. Возвращается код ошибки 1

## Использование в коде

```python
from converters.validation import ValidationConverter

env_vars = {
    'V8_SRC_PATH': 'C:/Projects/MyConfiguration'
}

converter = ValidationConverter(env_vars)
converter.validate()
result = converter.convert()  # Выполняет валидацию

if result == 0:
    print("Проект валиден!")
else:
    print("Обнаружены ошибки в проекте")
```
