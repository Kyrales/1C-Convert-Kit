## Архитектурные решения

### ExtensionConverter

1. **Три сценария подготовки базовой ИБ:**
   - Использование существующей ИБ (V8_BASE_IB)
   - Создание ИБ с конфигурацией (V8_BASE_CONFIG)
   - Создание пустой ИБ

2. **Поддержка двух инструментов:**
   - designer (1cv8.exe) - по умолчанию
   - ibcmd (ibcmd.exe) - альтернатива

3. **Маршрутизация по типу источника:**
   - EDT → 4 этапа (экспорт, подготовка ИБ, загрузка, выгрузка)
   - XML → 3 этапа (подготовка ИБ, загрузка, выгрузка)
   - IB → 1 этап (прямая выгрузка)

### ValidationConverter

1. **Переопределение базовой валидации:**
   - Не требует V8_DST_PATH (нет выходных файлов)
   - Проверяет только V8_SRC_PATH

2. **Многоуровневая проверка структуры:**
   - Базовая структура (DT-INF, .project)
   - Тип проекта (Configuration.xml или Extension.xml)
   - Дополнительная информация (src, количество файлов)

3. **Информативный вывод:**
   - Галочки ✓ для успешных проверок
   - Подробные сообщения об ошибках
   - Статистика по файлам
