## Технические детали

### Модуль gui_test_helper.py

Функция `skip_if_no_gui(test_name)`:
- Проверяет наличие PySimpleGUI/FreeSimpleGUI
- Проверяет возможность создания Tkinter окна
- Возвращает `True` если GUI доступен
- Возвращает `False` и выводит информативное сообщение если GUI недоступен

### Использование в тестах

```python
from tests.unit.gui_test_helper import skip_if_no_gui

# Проверяем наличие GUI
if not skip_if_no_gui("test_name.py"):
    exit(0)  # Пропускаем тест в headless режиме

# Далее идет код теста...
```
