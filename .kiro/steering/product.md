# Обзор продукта

**1C Convert Kit** - это GUI приложение для конвертации файлов 1С:Предприятие между различными форматами.

## Назначение

Предоставляет современный графический интерфейс в стиле Cyberpunk для пакетной конвертации конфигураций, обработок, отчетов и расширений 1С:Предприятие между форматами CF, CFE, EPF, ERF, XML и EDT.

## Ключевые возможности

- Пакетная конвертация проектов с отслеживанием прогресса
- Логирование и обновление статуса в реальном времени
- Гибкая настройка через .env файлы
- Поддержка множества типов конвертации (конфигурации, обработки, отчеты, расширения)
- Объединение базовой и проектной конфигурации
- Возможность указания пользовательского пути выгрузки

## Целевая аудитория

Разработчики и администраторы, работающие с 1С:Предприятие, которым необходимо конвертировать файлы между различными форматами (бинарные, XML, EDT проекты).

## Архитектура

Приложение на Python с современной объектно-ориентированной архитектурой:
- **GUI слой** (FreeSimpleGUI/PySimpleGUI) - графический интерфейс
- **Слой конвертеров** - специализированные Python классы для каждого типа конвертации
- **Базовый слой** - абстрактный BaseConverter с общей логикой
- **Слой абстракций инструментов** - обёртки над 1С инструментами (designer, ibcmd, 1cedtcli/ring)
- **Реестр конвертеров** - автоматическое обнаружение и регистрация конвертеров
- **Система конфигурации** - гибкая настройка через .env файлы

### Ключевые компоненты

**ConverterRegistry** - центральный реестр, который автоматически находит и регистрирует все доступные конвертеры по типу конвертации (conf2cf, dp2epf, ext2cfe и т.д.)

**BaseConverter** - абстрактный базовый класс с общей логикой:
- Валидация параметров
- Управление временными файлами
- Определение типа источника (EDT/XML/InfoBase)
- Единообразное логирование
- Обработка ошибок

**Специализированные конвертеры**:
- `ConfigurationConverter` - конвертация конфигураций (EDT/XML/IB → CF)
- `DataProcessorConverter` - конвертация обработок и отчетов (EDT/XML → EPF/ERF)
- `ExtensionConverter` - конвертация расширений (EDT/XML/IB → CFE)
- `ValidationConverter` - валидация EDT проектов

**Tool Wrappers** - абстракции для работы с инструментами 1С:
- `V8ToolWrapper` - работа с 1cv8.exe (designer)
- `IbcmdToolWrapper` - работа с ibcmd.exe
- `EdtToolWrapper` - работа с 1cedtcli/ring
