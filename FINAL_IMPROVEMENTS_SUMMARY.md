## Выполненные улучшения

### 1. ✅ Работа с буфером обмена для поля "Наименование"

**Что сделано:**
- Добавлено контекстное меню для поля "Наименование"
- Включена поддержка undo/redo
- Работают все стандартные операции:
  - Копировать (Ctrl+C)
  - Вставить (Ctrl+V)
  - Вырезать (Ctrl+X)
  - Выделить все (Ctrl+A)
  - Отменить (Ctrl+Z)

**Технические детали:**
```python
# Контекстное меню
right_click_menu = ['', ['Копировать', 'Вставить', 'Вырезать', 'Выделить все', '---', 'Отменить']]

# Поле Наименование с контекстным меню
sg.Input(current_name, key='-NAME-', size=(60, 1), 
        background_color=COLORS['bg_secondary'], 
        text_color=COLORS['text'],
        right_click_menu=right_click_menu)

# Включение undo для поля Наименование
for key in self.window.AllKeysDict:
    if isinstance(key, str) and (key.startswith('-VAL_') or key == '-NAME-'):
        element = self.window[key]
        if hasattr(element, 'Widget'):
            element.Widget.configure(undo=True, maxundo=-1)
```

## Исправленные проблемы

### Проблема: Падение приложения при открытии формы
**Причина:** Глобальные биндинги клавиш конфликтовали с PySimpleGUI

**Решение:** 
- Удалены глобальные биндинги `bind_all()`
- Контекстное меню Tkinter автоматически обрабатывает все операции
- Добавлена проверка типа ключа: `isinstance(key, str)`

### Проблема: Буфер обмена не работал
**Причина:** Отсутствовало контекстное меню и undo/redo

**Решение:**
- Добавлено контекстное меню для всех полей Input
- Включен undo/redo через `Widget.configure(undo=True)`
- Обработка событий контекстного меню
