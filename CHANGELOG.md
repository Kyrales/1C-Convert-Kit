# Changelog

Все заметные изменения 1C Convert Kit документируются в этом файле.

## [1.4.1] - 2026-09-19

### Первый публичный релиз

- Добавлены: графический интерфейс и CLI для пакетной конвертации артефактов
  `1С:Предприятие` между форматами CF, CFE, EPF, ERF, DT, XML и EDT.
- Поддержаны конвертация конфигураций, расширений, обработок и отчётов, загрузка
  конфигураций и расширений в информационные базы, а также выгрузка и загрузка DT.
- Добавлена проверка EDT-проектов через `1cedtcli`.
- Настройки проектов хранятся в `.env`; общие параметры можно задать один раз и
  переопределить для отдельного проекта.
- В GUI доступны создание, редактирование, копирование, группировка и пакетный запуск
  проектов, просмотр команд и журнала выполнения.
- Конвертеры переведены с legacy CMD-скриптов на единую Python-архитектуру с общим
  логированием, обработкой ошибок и сохранением временных файлов для диагностики.

Для выполнения конвертаций нужны соответствующие инструменты 1С: `1cv8.exe`,
`ibcmd.exe`, `1cedtcli` — набор зависит от выбранного сценария.
