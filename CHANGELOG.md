# Changelog

Все значимые изменения в проекте будут документированы в этом файле.

Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.0.0/),
и этот проект придерживается [Semantic Versioning](https://semver.org/lang/ru/).

## [1.2.0] - 2026-01-31

### Добавлено
- ✨ Полноценное управление проектами через GUI
  - Кнопка **Добавить** - создание нового проекта с визуальной формой
  - Кнопка **Изменить** - редактирование существующего проекта
  - Кнопка **Копировать** - создание копии проекта с возможностью изменения
  - Кнопка **Удалить** - удаление проекта с подтверждением
- 📝 Форма редактирования проекта с поддержкой всех параметров из `params_descriptions.json`
- ✅ Валидация имени проекта (недопустимые символы, дубликаты)
- 🔘 Чекбоксы для включения/выключения необязательных параметров
- 📂 Кнопки выбора файлов/папок для параметров путей
- 💡 Подсказки с описанием параметров при наведении
- 📊 Отображение базового .env файла в форме редактирования (только для просмотра)
- 🔄 Автоматическое переименование папок и файлов при изменении проекта
- 📖 Документация по управлению проектами ([docs/PROJECT_MANAGEMENT.md](docs/PROJECT_MANAGEMENT.md))

### Изменено
- 🎨 Командная панель управления проектами перенесена над таблицей проектов
- 📝 Обновлен README с инструкциями по использованию нового функционала
- 🔢 Версия приложения обновлена до 1.2.0

### Технические детали
- Добавлен класс `ProjectEditorDialog` для работы с формой редактирования
- Реализованы методы `_add_project()`, `_edit_project()`, `_copy_project()`, `_delete_project()`
- Добавлена валидация и санитизация имен проектов
- Реализовано автоматическое определение типов параметров (текст, путь к файлу, путь к папке, булево)
- Добавлена сортировка параметров: обязательные → включенные → выключенные

## [1.1.2] - 2026-01-30

### Добавлено
- Режим отладки с выводом команд в лог
- Улучшенная обработка кодировок вывода subprocess
- Цветное логирование с автоматическим определением типа сообщения

### Исправлено
- Проблемы с отображением русских символов в логе
- Зависание при выполнении длительных операций

## [1.1.0] - 2026-01-25

### Добавлено

- Пакетная конвертация проектов
- Детальная информация о параметрах проектов
